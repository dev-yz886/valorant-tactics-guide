## eDPI 数学公式与职业选手灵敏度区间分布
灵敏度绝对不是玄学，而是严格的物理移动映射比率：
- eDPI 计算公式：`eDPI = 鼠标硬件 DPI × 游戏内灵敏度（Sense）`；
- 职业选手的黄金区间（200 ~ 320 eDPI）：统计近千名 VCT 职业选手数据，超过 85% 的选手 eDPI 集中在 240~280 之间；
- 推荐基准搭配：鼠标硬件固定 800 DPI，游戏内灵敏度设置为 0.3~0.35（eDPI 约为 240~280）；此档位下，鼠标垫从中心向一侧滑到边缘刚好能在游戏内完成 180 度大转身防背刺，同时近距离微调极其稳健。

## 高敏手腕流 vs 低敏手臂流人体工程学
提升瞄准稳定性的手部关节分工法则：
- 高敏手腕流的弊端：纯靠手腕摆动虽然转头极快，但容易在紧张时手抖导致准星在爆头线上下剧烈跳动，且长期高强度玩极易引发腕管综合征；
- 手臂流与手腕流协同：大范围搜点、转头与转身依靠手肘作为支点的大臂肌肉摆动；当准星拉到敌人身周 3 厘米范围内，大臂锁死，依靠手腕与食指关节进行微米级精细瞄准，稳定性提升十倍。

## Windows 系统底层指针加速度与原始输入强制开启
必须在 Windows 控制面板【鼠标属性】中取消勾选【提高指针精确度】，斩断操作系统对物理滑行轨迹的非线性平滑扭曲；同时在无畏契约游戏设置中勾选【原始输入缓冲（Raw Input Buffer）】，让游戏直接从鼠标传感器直接读取原始数据包，响应延迟归零。

## 💡 常见高频答疑 (FAQ)

**问：从高灵敏度改到 800 DPI 0.3 感觉转不动头怎么办？**
答：换用尺寸至少在 450×400mm 以上的大号电竞鼠标垫，并在自定义房间中练习‘大臂甩刀’肌肉记忆，通常适应 3 到 5 天后爆头率即可产生质的飞跃。

**问：鼠标回报率开 4000Hz 或 8000Hz 会对游戏带来负面影响吗？**
