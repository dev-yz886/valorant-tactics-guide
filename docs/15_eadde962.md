## 一、隐世修所‘三包点’防守人员动态分配模型

隐世修所（Haven）是《无畏契约》中防守面积最大的一张地图，由于拥有 A、B、C 三个独立的爆能器安放点，防守方 5 名队员极易面临‘人手不足、顾此失彼’的被动局面。

**黄金 1-3-1 动态轮转模型**：
- **C 点长廊（1人）**：派遣尚勃勒或捷风手持大狙单人架死 C 长，凭借超远视距一人即可封死 C 点进攻；
- **B 点与中院（1人）**：控场烟位（如幽影）留在 B 点，利用技能支援两翼，同时监控中路庭院；
- **A 点与下水道（3人集中）**：由于 A 点拥有长廊、下水道双通道且回防距离最远，必须配置 3 人重兵把守，随时准备打前压拿信息。

## 二、A 下水道（A Sewer）快打强攻突破SOP

A 下水道是连接中路庭院与 A 大堂的暗道，地势狭窄但直通包点腹地：

1. **前点静音摸排**：进攻方开局不露脚步，利用幽影将下水道通往 A 花园的门洞封上一颗掩护烟；
2. **闪光破门**：先锋英雄向烟后推出闪光弹，决斗者踩着下水道木箱直接滑行跳出；
3. **夹击包点**：下水道突破力量与从 A 长廊正规推进的队友在同一秒开火，防守方在 A 包点柱子后顾前不顾后，瞬间被交叉枪线撕碎。

## 三、自由人（Lurker）断后与残局截杀SOP

在全队决定主攻 C 包点时，指派一名自由人（如零或蝰蛇）单人悄悄摸入 A 点下水道。当防守方 A 点守军听到 C 点爆弹仓皇向 C 点回防奔跑时，自由人从其身后悄然杀出，轻松连收两个毫无防备的奔跑背身，一举终结整局比赛。
