# 游戏闪退报错VAN 1067与VAN 9003排查修复全景：主板UEFI设置、VGC服务与系统冲突清理

> **核心导读**：手把手解决无畏契约高频错误代码VAN 1067、VAN 9003、VAN 128，修复Windows服务组件，主板安全启动与系统完整性指南。

## VAN 9003 报错根因与 BIOS 安全启动激活指南
升级 Win11 后最普遍的报错是 VAN 9003（This build of Vanguard requires Secure Boot）：
- 故障根源：主板处于传统 CSM 兼容模式，或未在 BIOS 中启用 UEFI 与 Secure Boot；
- 修复标准步骤：
  1. 重启电脑连续狂按 Del 键或 F2 键进入主板 BIOS 界面；
  2. 进入【Boot（启动）】或【Security（安全）】设置选项；
  3. 将【CSM Support】设置为【Disabled（关闭）】；
  4. 将【Secure Boot（安全启动）】设置为【Enabled（开启）】，并将操作系统模式改为【Windows UEFI Mode】；
  5. 按 F10 保存并重启电脑，即可永久消除 VAN 9003 弹窗。

## VAN 1067 报错与 VGC 系统服务异常自愈方案
VAN 1067 通常指示系统后台的核心支撑服务 `vgc` 发生异常崩溃或被安全软件强行拦截：
- 检查服务状态：按 Win+R 输入 `services.msc` 打开系统服务列表；
- 定位 vgc 服务：找到名为【vgc】的服务，右键属性将启动类型修改为【自动】；
- 启动权限修复：若 vgc 处于停止状态，手动点击启动。如果启动报错，多半是系统防火墙或第三方清理软件禁止了 Vanguard 开机自启，将其加入信任白名单并重启系统即可自愈。

## VAN 128 与系统内核完整性校验
在管理员权限命令提示符中依次输入 `sfc /scannow` 与 `DISM /Online /Cleanup-Image /RestoreHealth`，修复被误损坏的 Windows 系统底层动态链接库，确保反作弊进程与操作系统内核无障碍通讯。

## 💡 常见高频答疑 (FAQ)

**问：关闭 CSM 之后电脑黑屏进不去系统怎么办？**
答：说明系统硬盘的分区格式为老式 MBR 而非 GPT。需在 Windows 中使用 `mbr2gpt` 工具将引导盘无损转换为 GPT 格式后再关闭 CSM。

**问：重新安装 Vanguard 之后为什么依然报错？**
答：必须在卸载后彻底重启一次电脑，让旧版驱动彻底脱离内核驻留，然后再以管理员身份运行拳头客户端进行全新静默安装。
