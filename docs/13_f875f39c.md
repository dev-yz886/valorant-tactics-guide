## Ring 0 操作系统最高特权级驻留机制
拳头 Vanguard 是全球最严苛的电竞反作弊底层系统之一，其核心驱动文件为 `vgk.sys`：
- 随系统开机自启：与其他在游戏启动时才加载的普通反作弊不同，Vanguard 作为内核模式驱动，在 Windows 系统开机引导的第 1 帧即刻加载驻留；
- 内存完整性保护：严密拦截任何企图通过 `OpenProcess` 等 API 向游戏注入 DLL 模块的行为，对游戏主进程（VALORANT-Win64-Shipping.exe）设立严苛的内存句柄隔离罩；
- 硬件虚拟化防碰撞：深度校验 CPU 虚拟化状态，对不合规的虚拟机沙盒环境实施一票否决。

## TPM 2.0 硬件芯片与 Secure Boot 安全启动握手
Windows 11 环境下硬性绑定的硬件级安全标准：
- TPM 2.0 硬件根信任：主板搭载的受信任平台模块（TPM 2.0）用于存储唯一的平台身份密钥，防止任何对引导链条的篡改；
- 安全启动（Secure Boot）数字签名锁：在 UEFI 阶段只允许加载微软官方认证签名的操作系统核心文件，杜绝通过加载恶意内核驱动实施绕过；
- 硬件握手失败后果：若 BIOS 中未启用上述两项技术，游戏在启动时将直接弹窗报错拒绝进入匹配。
